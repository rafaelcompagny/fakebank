# Correctif thème sombre — Paiements RafaTech

Le correctif force les composants de `merchant-payments.html` à utiliser
le thème sombre Cryptex et empêche les styles génériques `.card` / `.list-item`
de remettre un fond blanc.

Éléments corrigés :
- détails HT / TVA / compte / date ;
- avertissement de sécurité ;
- historique ;
- état vide ;
- bouton Autoriser ;
- bouton Refuser ;
- cartes et compteur.
